# Blog Application with GenAI

## Tech Stack
Frontend: React.js
Backend: Node.js (Express)
Database: SQLite
AI: OpenAI API

## Setup

### Backend
cd backend
npm install
cp .env.example .env
# Add your OpenAI key
node server.js

### Frontend
cd frontend
npm install
npm start

## Features
- Full CRUD
- AI Suggestions
- Edit/Delete
- Environment Config
- Pixel-aligned UI
